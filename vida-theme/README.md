# VIDA · فيدا — ثيم متجر مجوهرات فضة

ثيم متجر فاخر بطابع عالمي لمتجر **فيدا** للمجوهرات الفضية. عربي بالكامل (RTL)، متجاوب مع الجوال، ويعمل بدون أي مكتبات خارجية.

## الصفحات
| الملف | الوصف |
|---|---|
| `index.html` | الرئيسية: سلايدر بنرات (3 شرائح)، شريط المزايا، الفئات، منتجات بتبويبات (الأكثر مبيعاً / جديد / عروض)، بنر عرض بعدّاد تنازلي، قصة العلامة، بنرات الهدايا والحفر، قسم الرجال، التقييمات، معرض إنستقرام، النشرة البريدية |
| `shop.html` | المتجر: فلترة بالفئة والسعر والعروض، ترتيب، بحث، المفضلة (`?cat=rings` · `?sale=1` · `?wish=1` · `?q=عقيق`) |
| `product.html` | صفحة المنتج: معرض صور مع تكبير، المقاسات، الحفر المجاني، الكمية، تقسيط تمارا/تابي، المواصفات، منتجات مشابهة، زر شراء ثابت على الجوال (`?id=p01`) |
| `cart.html` | السلة: تعديل الكميات، كود خصم (`VIDA10` · `WELCOME15`)، شريط الشحن المجاني، الإجمالي |
| `about.html` | قصتنا وقيم العلامة |

## الملفات
```
assets/css/style.css        التصميم كامل (الألوان والخطوط في :root)
assets/js/products.js       بيانات المنتجات والفئات — عدّل هنا الأسماء والأسعار
assets/js/main.js           الهيدر والفوتر والسلة والمفضلة والسلايدر والصفحات
assets/img/products/*.svg   16 صورة منتج فضي (خواتم، قلائد، أقراط، أساور، خلخال)
assets/img/banners/*.svg    بنرات الهيرو والعروض والهدايا والقصة
tools/generate_assets.py    سكربت توليد الصور والبنرات
```

## التشغيل
```bash
cd vida-theme
python3 -m http.server 8000
# افتح http://localhost:8000
```

## التخصيص
- **الألوان والخطوط:** متغيرات `:root` في أول `style.css` (`--ink` الأسود، `--ivory` الخلفية، `--silver-grad` التدرج الفضي).
- **المنتجات:** أضف عنصراً في `VIDA_PRODUCTS` داخل `products.js`، مع الحقول `img` و`cat` و`price` و`old` (السعر قبل الخصم) و`sizes`.
- **الصور الحقيقية:** ضع صورك في `assets/img/products/` وغيّر دالة `IMG` في `main.js` لتقبل امتداد `.jpg` أو `.webp`.
- **الشحن المجاني وأكواد الخصم:** الثوابت `FREE_SHIP` و`SHIP_FEE` و`COUPONS` في أعلى `main.js`.
- **البنرات:** عدّل `tools/generate_assets.py` ثم شغّل `python3 tools/generate_assets.py`، أو استبدل ملفات `banners/*.svg` بصورك (المقاس المقترح للهيرو 1600×800).

> ملاحظة: الدفع وتسجيل الدخول واجهات عرض فقط. عند النقل إلى منصة مثل سلة أو زد أو شوبيفاي، انقل ملف CSS والأقسام إلى قوالب المنصة، واربط السلة ببوابة الدفع.
