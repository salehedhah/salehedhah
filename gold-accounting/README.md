# نظام محاسبة الذهب ◆

نظام محاسبي سحابي لمحلات الذهب والمجوهرات في السعودية. يغطي الفواتير والمخزون بالوزن والقيود المزدوجة والتقارير المالية وإقرار ضريبة القيمة المضافة، ومجهّز للربط مع منصة **فاتورة** التابعة لهيئة الزكاة والضريبة والجمارك.

## المزايا

| القسم | ما يقدمه |
|---|---|
| **الفواتير** | فواتير بيع مبسطة (B2C) وضريبية (B2B)، فواتير شراء، إشعارات دائنة ومدينة (مرتجعات). الحساب بالوزن والعيار وسعر الجرام والمصنعية، مع خصم وضريبة تلقائية |
| **ضريبة الذهب** | المشغولات الذهبية بنسبة 15%، والذهب الاستثماري (سبائك وجنيهات نقاوتها 99% فأكثر) بنسبة صفرية، والشراء من الأفراد (ذهب مستعمل) بدون ضريبة مدخلات |
| **الفوترة الإلكترونية** | رمز QR للمرحلة الأولى، وملف XML بصيغة UBL 2.1، وعداد الفواتير (ICV)، وسلسلة البصمات (PIH)، ومعرّف UUID لكل فاتورة، وواجهة إرسال للإبلاغ والاعتماد |
| **المخزون** | أرصدة كل عيار (24، 22، 21، 18) بالجرام، ومتوسط التكلفة المرجح، والقيمة السوقية، والمعادل بعيار 24، وسجل الحركة، والرصيد الافتتاحي |
| **المحاسبة** | دليل حسابات جاهز لمحل ذهب، وقيد آلي لكل عملية، وقيود يدوية، وكشف حساب لأي حساب |
| **التقارير** | التقرير الشهري، وقائمة الدخل، وقائمة المركز المالي، وقائمة التدفقات النقدية، وميزان المراجعة |
| **الإقرار الضريبي** | إقرار ضريبة القيمة المضافة بخانات نموذج الهيئة (1 إلى 16) لأي فترة (شهرية أو ربع سنوية) |
| **الزكاة** | تقدير الوعاء الزكوي (هجري 2.5% أو ميلادي 2.5776%) مع تقييم المخزون بسعر السوق |
| **المستخدمون** | صلاحيات: مدير النظام، محاسب، كاشير، مع سجل للعمليات ونسخ احتياطي |

## التشغيل على جهازك

المتطلبات: Node.js 20 أو أحدث.

```bash
cd gold-accounting
npm install
npm start
```

بعدها افتح `http://localhost:3000`. أول مرة يطلب منك النظام إنشاء حساب المدير. بعد الدخول:

1. **الإعدادات**: أدخل بيانات المنشأة والرقم الضريبي والعنوان، لأنها تظهر في الفواتير وفي رمز QR.
2. **لوحة التحكم**: حدّث سعر جرام عيار 24 يومياً، وتُحسب باقي الأعيرة تلقائياً.
3. **مخزون الذهب**: أدخل الرصيد الافتتاحي لكل عيار.
4. إذا عندك نقدية أو رأس مال سابق، سجّله بقيد يدوي (مدين الصندوق أو البنك، دائن رأس المال).

## التشغيل السحابي

### باستخدام Docker (أي خادم VPS)

```bash
cd gold-accounting
docker compose up -d --build
```

- البيانات محفوظة في الـ volume `gold-data`.
- غيّر قيمة `SESSION_SECRET` في `docker-compose.yml` إلى نص عشوائي طويل.
- ضع النظام خلف HTTPS (مثل Caddy أو Nginx مع Let's Encrypt)، ولا تشغّله على HTTP في الإنترنت.

### منصات جاهزة (Railway، Render، Fly.io)

- اربط المستودع، واختر مجلد `gold-accounting` كجذر للمشروع، وأمر التشغيل `npm start`.
- أضف قرص تخزين دائم (Persistent Volume) واضبط `DATA_DIR` على مساره، وإلا تضيع البيانات مع كل إعادة تشغيل.

### متغيرات البيئة

| المتغير | الوصف |
|---|---|
| `PORT` | منفذ الخادم (الافتراضي 3000) |
| `DATA_DIR` | مجلد قاعدة البيانات (الافتراضي `./data`) |
| `SESSION_SECRET` | مفتاح توقيع الجلسات. إذا لم تضبطه يولَّد مفتاح ويُحفظ في قاعدة البيانات |
| `COOKIE_SECURE` | اضبطه على `1` عند التشغيل خلف HTTPS |

## الربط مع هيئة الزكاة والضريبة والجمارك

**يعمل الآن:**
- رمز QR بصيغة TLV على كل فاتورة بيع وإشعار دائن، وفق متطلبات المرحلة الأولى.
- توليد XML بصيغة UBL 2.1 لكل فاتورة مع UUID وICV وPIH وبصمة SHA-256.
- تنزيل ملف XML من صفحة الفاتورة، وزر «إرسال لمنصة فاتورة» يستدعي واجهات الإبلاغ (للمبسطة) والاعتماد (للضريبية).

**مطلوب لإكمال المرحلة الثانية (الربط والتكامل):**
1. تسجيل المنشأة في بوابة فاتورة والحصول على رمز OTP.
2. توليد CSR ومفتاح خاص (ECDSA secp256k1) والحصول على شهادة الامتثال (Compliance CSID)، ثم اجتياز فحوصات الامتثال، ثم الحصول على شهادة الإنتاج (Production CSID).
3. التوقيع الرقمي XAdES للفاتورة، وإضافة حقول QR من 6 إلى 9 (البصمة، التوقيع، المفتاح العام، توقيع الشهادة).
4. التحقق من الملفات بأداة ZATCA SDK الرسمية قبل التشغيل الفعلي.

البندان 2 و3 هما الخطوة البرمجية التالية. بعد إكمالها تدخل بيانات CSID في **الإعدادات ← الربط مع الهيئة**.

> **ملاحظة:** الهيئة لا توفر واجهة برمجية لتقديم إقرار ضريبة القيمة المضافة. النظام يجهّز الإقرار بخانات النموذج الرسمي، وأنت تدخل الأرقام في بوابة الهيئة. ويُفضل مراجعة الإقرار والزكاة مع محاسب قانوني.

## القواعد المحاسبية المطبقة

- **البيع:** مدين الصندوق/البنك/العملاء. دائن مبيعات الذهب والمصنعية وضريبة المخرجات. مدين تكلفة الذهب المباع ودائن المخزون، بمتوسط التكلفة المرجح.
- **الشراء:** مدين المخزون (الذهب مع المصنعية) وضريبة المدخلات. دائن الصندوق أو الموردين.
- **المرتجعات:** قيد عكسي، ويعود الذهب للمخزون بتكلفته الأصلية.
- لا يمكن حذف الفواتير، والتصحيح يكون بالمرتجع (متطلب نظامي). ولا يمكن بيع وزن أكثر من المتوفر في المخزون.

## البنية التقنية

- **الخادم:** Node.js وExpress وSQLite (better-sqlite3)
- **الواجهة:** HTML وCSS وJavaScript بدون أطر عمل، عربية بالكامل (RTL)، وتعمل على الجوال
- **الملفات:** `server/accounting.js` (المحرك المحاسبي)، `server/reports.js` (التقارير)، `server/zatca.js` (الفوترة الإلكترونية)، `server/index.js` (الواجهات البرمجية)، `public/` (الواجهة)
